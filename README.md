# Abdelhalim Azzouz — Academic Website

Personal academic website built with Quarto and deployed with GitHub Pages.

## Local preview

Install Quarto, then run:

```bash
quarto preview
```

## Deployment

Push this repository to `Azzouz1972/Azzouz1972.github.io`. The included GitHub Actions workflow renders the site and publishes it to the `gh-pages` branch.

In GitHub: **Settings → Pages → Build and deployment → Source → Deploy from a branch**, then select `gh-pages` and `/ (root)` if GitHub does not select it automatically.
